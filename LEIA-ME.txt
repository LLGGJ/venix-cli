COMO APLICAR
1. Copie o conteúdo do ZIP por cima do repositório (mantendo as pastas).
2. Antes de subir (não foi possível compilar Go aqui):
     make fmt && go vet ./... && go test ./... && go build -o /tmp/v ./cmd/venix && /tmp/v doctor
3. git add -A && git commit && git push, e envie a tag v1.0.17 (o site já cria a tag).
