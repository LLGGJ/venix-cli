VENIX CLI - CORREÇÃO DE RELEASE + TUI RESPONSIVO DO `venix apps`

COMO APLICAR
1. Copie o conteúdo deste ZIP por cima do repositório (mantendo as pastas).
2. APAGUE do repositório (git rm): .goreleaser.yaml e npm-package/bin/venix-native
3. Rode no seu PC/Termux (não foi possível rodar Go aqui):
     make fmt && go vet ./... && go test ./... && go build -o /tmp/v ./cmd/venix && /tmp/v --version
4. git add -A && git commit -m "release: pipeline + apps responsivo"
   git push origin main
   git tag v1.0.5 && git push origin v1.0.5
