VENIX CLI v1.0.26  (nota de entrega: NÃO precisa ir para o repositório, pode apagar depois de ler)

COMO APLICAR
1. Extraia este ZIP por cima da pasta do repositório venix-cli, mantendo as pastas.
   Não mexa em app/, components/ e lib/ (não fazem parte da CLI).
2. Se o seu .gitignore tem regras do site, mantenha o seu e só acrescente:
     npm-package/bin/venix-native*
     *.tgz
3. Rode: make fmt && go vet ./... && go test ./...
4. git add -A && git commit  e depois: git tag v1.0.26 && git push origin v1.0.26

O QUE MUDOU NESTA VERSÃO
- Instaladores (install.sh, install.ps1, npm): mensagem "<emoji> <sistema> detectado" em formato de cartão.
- Backup: removido do menu do app e escondido do help (a API ainda não tem a rota).
- Ver logs: cada pedido à API é mais leve (cache de métricas, intervalo de 10s, pausa em HTTP 429);
  logs e métricas organizados em seções (RESUMO, LOGS, AMOSTRAS) na tela de logs.
- Detalhes: dividido em seções APLICAÇÃO / ENDEREÇO / RECURSOS; corrige "82.82GB MB" na memória.
- Limpa a tela automaticamente nos comandos interativos (VENIX_NO_CLEAR=1 desativa).
- HTTP 429 agora mostra mensagem amigável.
